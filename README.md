# ☕ Кафе — 2D-симулятор кафе для Android

Игра по [ТЗ](./тз.md): Phaser 3 (JavaScript) + Capacitor, портретная ориентация, хранение в `localStorage`, работает без интернета. Графика — эмодзи и векторные фигуры, звуки синтезируются WebAudio, внешних ассетов нет.

## Как играть

1. Гость приходит в очередь (сверху). Нажмите на **первого в очереди** — он сядет за свободный чистый столик.
2. Над гостем на 4,5 с появится **записка-рецепт**: три значка (основа → добавка → подача) и, возможно, условие («без сахара», «двойной шот», «без молока», «холодное мороженое»). Запомните!
3. Откройте **🍳 Кухню**, выберите заказ и соберите напиток в правильном порядке. Ошибка на шаге — переделка и потеря времени.
4. Включите нужные переключатели условий (🍬 Сахар, 🥛 Пенка, ☕×2 Шот, ❄️ Лёд) и нажмите **🛎️ Подать**, пока не кончилось терпение гостя.
5. Монеты тратятся в **🛒 Магазине** на столики, ускорение, новые ингредиенты и декор.

Забыли заказ? Загляните в **📒 Блокнот** (но при длинной очереди записи могут быть с ошибками!) или нажмите на гостя — подсказка стоит 15% его терпения.

## Что реализовано по ТЗ

| Раздел ТЗ | Реализация |
|---|---|
| Характеры клиентов | ⚡ торопыга (45 с, щедрые чаевые), 😌 спокойный (100 с, платит 70%), 🧐 привереда (всегда с условием; не платит, если условие нарушено) |
| Многошаговый заказ | основа → добавка → подача, ошибка = переделка (2 с, уменьшается улучшением) |
| Записка-рецепт | три иконки над гостем, нужно запомнить порядок |
| Блокнот у кассы | отдельный экран; шанс ошибки в записи = 12% × длина очереди (до 50%) |
| Условия заказа | проверяются при выдаче; нарушение = −50% и без чаевых (привереда — 0) |
| Рецепты-открытия | вкладка «⚗️ Опыт» на кухне: 3 ингредиента в любом порядке; 8 секретных рецептов + сезонные |
| Взбивание сливок | кнопка «Взбить» всегда + тряска телефона (вкл. в настройках, по умолчанию выкл., только на этом экране), полоска с зелёной зоной, порог чувствительности в настройках |
| Случайные события | 📸 блогер (×2 оплата 30 с), 💥 поломка кофемашины (мини-игра починки болтов), 🕵️ санэпидемстанция (через 20 с проверка чистоты: грязные столы и лужи) |
| Апгрейды | столик 50 💰 (×1.6 после покупки), ускорение 30 💰 (×1.5) |
| Ачивки и звёзды | 13 ачивок, каждая = ⭐; звёзды открывают столики (3-й — 1⭐, 4-й — 3⭐) и декор |
| Постоянные клиенты | запоминают любимый заказ, говорят «как обычно»; угадали без подсказки и ошибок — +15 💰 |
| Оффлайн-прогресс | пассивный доход за время отсутствия, максимум 2 часа |
| Сезоны и декор | сезон по дате: 🎃 тыквенный латте осенью, 🍬 новогодние напитки зимой, 🌸 весной, 🍓 летом; цвет стен, мебель, украшения |
| Экраны | главный, кухня, блокнот, магазин, настройки (+ взбивание, починка) |
| Сохранение | при каждом изменении, при сворачивании и выходе (`visibilitychange`, `pagehide`, Capacitor `App.pause`) |
| Экран | 720×1280, `Scale.FIT` — на 16:9 и 9:16 ничего не обрезается |

Открытые вопросы ТЗ решены так: только русский язык; простые синтезированные звуки (выключаются в настройках), без музыки; баланс — стартовый, подбирается при тестировании (цены в `src/data.js` и `src/state.js`).

## Запуск

```bash
npm install
npm run dev        # игра в браузере: http://localhost:5173
npm run build      # сборка в dist/
```

## Сборка под Android

Нужны Android Studio и JDK 21.

```bash
npm run android    # build + cap sync + открыть проект в Android Studio
```

Дальше в Android Studio: **Build → Generate Signed App Bundle / APK** (AAB для Google Play).
Минимальная версия — Android 7.0 (minSdk 24), т.е. Android 8.0+ поддерживается. Ориентация зафиксирована портретная (`AndroidManifest.xml`).

## Структура

```
src/
  main.js              конфиг Phaser, список сцен
  data.js              ингредиенты, рецепты, клиенты, ачивки, декор, сезоны
  state.js             сохранение, экономика, оффлайн-доход, генерация заказов
  ui.js                кнопки, модальные окна, полоски
  audio.js             звуки WebAudio
  motion.js            детектор тряски (акселерометр)
  scenes/
    MainScene.js       зал: очередь, столики, события, чистота
    KitchenScene.js    приготовление, условия, опыты
    WhipScene.js       взбивание сливок
    RepairScene.js     починка кофемашины
    NotepadScene.js    блокнот, книга рецептов, постоянные гости
    ShopScene.js       улучшения, меню, декор, ачивки
    SettingsScene.js   тряска, чувствительность, звук, сброс
    ToastScene.js      уведомления
android/               нативный проект Capacitor
```
